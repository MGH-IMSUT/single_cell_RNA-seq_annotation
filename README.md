When analyzing the FASTQ files generated by amplification and sequencing according to the method described in the related paper using this code, a CSV file containing the read counts of 10xbarcode-randomDNA barcode combinations is produced.
anno.txt links single-cell data from mice 1–4 to clone output information. “10x” represents the single-cell ID, “BC” represents the clone ID, and “Cluster” indicates the clone classification: c1 = P-HSCs, c2 = PRG-HSCs, c3 = PRGB-HSCs, and c4 = balanced-HSCs.
